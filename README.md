# Data Center GeoLocator 
## A collaboration between Earth Genome and EPIC 


## What? 
An R&D effort to identify characteristics of data centers utilizing remote sensing

## Why? 
Data on datacenters is sparse, particularly cite level characteristics like footprint, ecosystems impacted, cooling etc. 

## Data Sources

- Data center location datasets are stored in `raw-data/data-center-locations/`.
- Imagery source notes are stored in `raw-data/imagery-sources/`.
